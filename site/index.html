Provider Independence — Every provider (ASR, Reasoning, TTS) is a standalone module with zero cross-dependencies. Swapping Faster-Whisper for Moonshine, or Kokoro for Piper, requires writing one driver file and touching nothing else.

// Launch Sequence

Get Started

Running in under 5 minutes. Python 3.10+ · Node.js 18+ · Ollama · CUDA GPU

01

Pull the reasoning model

Ollama downloads and manages the model weights automatically.

ollama pull hf.co/HauhauCS/Qwen3.5-4B-Uncensored-HauhauCS-Aggressive:Q4_K_M
02

Place the VAD model

Download Silero VAD v5 and place silero_vad_v5.onnx in frontend/public/

03

Launch everything

One-click on Windows, or manual two-terminal setup.

# Option A: One-click (Windows) run_sentri.bat # Option B: Manual cd backend && .\venv\Scripts\activate uvicorn app.main:app --reload --port 8008 # In a second terminal cd frontend && npm install && npm run dev -- -p 3030
04

Open the HUD

Navigate to localhost:3030 and start talking to SENTRI. ASR and TTS models auto-download on first launch.
