# ADR-0007: Provider Independence

## Status
Approved

## Context
Sentinel V2 implements a modular, decoupled speech pipeline composed of ASR (Speech-to-Text), Reasoning (LLM), Chunker, and TTS (Text-to-Speech) components. As the project expands, maintaining strict separation of concerns is vital to ensure that providers remain interchangeable and easily testable.

## Decision
We enforce a strict rule of **Provider Independence**:
* **No provider implementation may import, depend on, or communicate directly with another provider.**
* All communication and data passing must be orchestrated exclusively by `StreamingSpeechPipeline`.
* All exchanges between components must pass through the strongly typed, formal schemas defined in `contracts.py`.

## Consequences
* **Extreme Interchangeability**: Replacing an ASR engine (e.g., swapping Faster-Whisper for Moonshine) requires writing a single provider driver and does not affect the Reasoning or TTS codebases.
* **Ease of Testing**: Providers can be unit-tested in isolation by feeding them mock contract payloads.
* **Architectural Cleanliness**: Prevents spaghetti-like coupling between disparate cognitive domains.
